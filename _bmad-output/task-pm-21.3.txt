Story 21.3: API Endpoints for Staffing Needs

From the epics doc:
- GET /api/staffing-needs — returns { data: StaffingNeedWithProgress[], meta: { timestamp } }
- PUT /api/staffing-needs — body { location, headcount_need }, returns { data: { location, old_value, new_value }, meta: { timestamp } }. 403 for non-hr_admin/crewing roles. Triggers async email notification.

- 400 for invalid location

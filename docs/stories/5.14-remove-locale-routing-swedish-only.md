# Story 5.14: Remove Locale Routing (Swedish-Only Application)

**Epic:** 5.5 - Post-MVP Polish & Branding  
**Story ID:** 5.14  
**Priority:** P1 (High)  
**Estimated Effort:** 3-4 hours  
**Status:** Ready for Review

---

## User Story

As a **developer and end user**,  
I want **the application to be Swedish-only without locale routing complexity**,  
so that **the codebase is simpler, URLs are cleaner, and text constants remain maintainable**.

---

## Business Context

**Requirement Clarification:** User confirmed that multi-language support (Swedish/English) is NOT needed. The application should be **Swedish-only**.

**Current Problem:** The application was built with full bilingual support including:

- \
  ext-intl\ package (adds ~50KB to bundle)
- Locale routing with \/sv/\ and \/en/\ URL prefixes
- Language toggle UI (flag buttons in header)
- Maintenance burden of two translation files

**User Insight:** While multi-language is not needed, keeping \messages/sv.json\ as centralized text constants provides:

- Single source of truth for all Swedish text
- Easy content updates without touching code
- Consistency across the application
- Future-proofing if multi-language is needed later

### Translation Pattern Change

**Before (next-intl):**
\\\ ypescript
import { useTranslations } from 'next-intl';

export default function Component() {
const t = useTranslations('common');
return <Button>{t('save')}</Button>;
}
\\\

**After (simple utility):**
\\\ ypescript
import { t } from '@/lib/i18n';

export default function Component() {
return <Button>{t.common.save}</Button>;
}
\\\

### Middleware Simplification Example

**Remove these patterns:**
\\\ ypescript
// REMOVE: Locale extraction
const locale = firstSegment;
const pathWithoutLocale = pathname.slice(locale.length + 1) || '/';

// REMOVE: Locale validation
const isValidLocale = locales.includes(firstSegment as (typeof locales)[number]);

// REMOVE: Intl middleware integration
const intlMiddleware = createMiddleware({ ... });
return intlMiddleware(request);
\\\

**Update redirect patterns:**
\\\ ypescript
// BEFORE:
const redirectUrl = new URL(\/\/dashboard\, request.url);

// AFTER:
const redirectUrl = new URL('/dashboard', request.url);
\\\

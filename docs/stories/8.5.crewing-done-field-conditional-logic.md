# Story 8.5: Crewing/Done Field Conditional Logic

## Status

**Done**

---

## Story

**As an** HR Admin,  
**I want** Crewing/Done to only be editable when all prerequisite fields are completed,  
**So that** I enforce completion requirements before marking as crew-ready.

---

## Acceptance Criteria

1. Crewing/Done field is disabled unless ALL of the following are true: ISP, Photo, Origo, Mail, lön, Bankuppgifter, LI, Passport, Kvitto C17/18, C17 (10 fields total)
2. Visual indicator shows which fields are incomplete when Crewing/Done is disabled
3. Tooltip on disabled Crewing/Done lists incomplete prerequisite fields
4. When all prerequisites are met, Crewing/Done becomes editable
5. When Crewing/Done is set to true, display green badge ("✓ Complete")
6. API validation enforces prerequisite check before allowing Crewing/Done update (server-side validation)
7. If any prerequisite field is later set to false, Crewing/Done field becomes disabled but value remains unchanged
8. Employee table visually indicates which employees are crew-ready (Crewing/Done = true)
9. Filtering by "Crew Ready" status works correctly
10. Export includes Crewing/Done status and prerequisite completion summary
11. Performance: prerequisite checking doesn't degrade table rendering
12. Real-time: prerequisite status updates immediately when any required field changes

### Business Logic Service

**File Location:** `src/lib/services/crewing-validation.ts`

**Function Specifications:**

```typescript
/**
 * Prerequisite fields required for Crewing/Done editability.
 * All 10 fields must be true before Crewing/Done can be edited.
 */
const REQUIRED_FIELDS = [
  'isps',
  'photo',
  'origo',
  'mail_lon',
  'lon',
  'bankuppgifter',
  'li',
  'passport',
  'kvitto_c17_18',
  'c17',
] as const;

/**
 * Field name to display name mapping for user-friendly messages.
 */
const FIELD_LABELS: Record<string, string> = {
  isps: 'ISP',
  photo: 'Photo',
  origo: 'Origo',
  mail_lon: 'Mail',
  lon: 'lön',
  bankuppgifter: 'Bankuppgifter',
  li: 'LI',
  passport: 'Passport',
  kvitto_c17_18: 'Kvitto C17/18',
  c17: 'C17',
};

/**
 * Determine if Crewing/Done field can be edited based on prerequisite completion.
 *
 * Business Rule: All 10 prerequisite masterdata fields must be true before
 * an employee can be marked as crew-ready (Crewing/Done = true).
 *
 * @param employee - Employee object with prerequisite fields
 * @returns true if all prerequisites are met, false otherwise
 */
export function canEditCrewingDone(employee: Partial<Employee>): boolean {
  return REQUIRED_FIELDS.every((field) => employee[field] === true);
}

/**
 * Get list of incomplete prerequisite fields for display in tooltips/errors.
 *
 * @param employee - Employee object with prerequisite fields
 * @returns Array of display names for incomplete fields
 */
export function getIncompleteFields(employee: Partial<Employee>): string[] {
  return REQUIRED_FIELDS.filter((field) => employee[field] !== true).map(
    (field) => FIELD_LABELS[field]
  );
}
```

**Performance Consideration:** The `canEditCrewingDone` function is O(10) - checks exactly 10 fields. This is negligible and will not cause performance issues even with 1000+ employees.

```typescript
interface EditableCellProps {
  // ... existing props
  canEdit?: boolean;
  employeeData?: Partial<Employee>; // For Crewing/Done field only
}

export function EditableCell({
  value,
  employeeId,
  field,
  type,
  canEdit = true,
  employeeData,
  onSave,
  onError,
}: EditableCellProps) {
  // Determine if this is the Crewing/Done field
  const isCrewingField = field.toLowerCase() === 'crewing_done';

  // Calculate conditional editability for Crewing/Done
  let effectiveCanEdit = canEdit;
  let tooltipMessage = '';

  if (isCrewingField && employeeData) {
    effectiveCanEdit = canEditCrewingDone(employeeData);

    if (!effectiveCanEdit) {
      const incomplete = getIncompleteFields(employeeData);
      tooltipMessage = `Missing prerequisites: ${incomplete.join(', ')}`;
    }
  }

  // Disabled state styling
  const disabledClass = !effectiveCanEdit ? 'opacity-50 cursor-not-allowed' : '';

  // Read mode rendering with conditional tooltip
  if (!isEditing) {
    const content = (
      <div
        className={cn(
          'flex items-center gap-2 px-3 py-2',
          effectiveCanEdit && 'cursor-pointer hover:bg-muted/50',
          disabledClass
        )}
        onClick={() => effectiveCanEdit && setIsEditing(true)}
      >
        <span>{displayValue}</span>
        {type === 'boolean' && value && <StatusBadge status="green" />}
      </div>
    );

    // Wrap disabled Crewing/Done in tooltip
    if (isCrewingField && !effectiveCanEdit) {
      return (
        <Tooltip>
          <TooltipTrigger asChild>{content}</TooltipTrigger>
          <TooltipContent>
            <p>{tooltipMessage}</p>
          </TooltipContent>
        </Tooltip>
      );
    }

    return content;
  }

  // ... rest of component (edit mode logic)
}
```

### API Validation

**PATCH /api/employees/[id]:**

Location: `src/app/api/employees/[id]/route.ts`

```typescript
import {
  canEditCrewingDone,
  getIncompleteFields,
} from '@/lib/services/crewing-validation';

// In PATCH handler
if ('crewing_done' in validatedData) {
  // Get current employee with all prerequisite fields
  const currentEmployee = await db.query.employees.findFirst({
    where: eq(employees.id, params.id),
    columns: {
      isps: true,
      photo: true,
      origo: true,
      mail_lon: true,
      lon: true,
      bankuppgifter: true,
      li: true,
      passport: true,
      kvitto_c17_18: true,
      c17: true,
    },
  });

  if (!currentEmployee) {
    return NextResponse.json(
      { error: { message: 'Employee not found' } },
      { status: 404 }
    );
  }

  // Check if Crewing/Done can be edited
  if (!canEditCrewingDone(currentEmployee)) {
    const incomplete = getIncompleteFields(currentEmployee);
    return NextResponse.json(
      {
        error: {
          message: `Cannot edit Crewing/Done - prerequisites not met: ${incomplete.join(', ')}`,
          code: 'CREWING_DONE_PREREQUISITES_NOT_MET',
          details: { incompleteFields: incomplete },
        },
      },
      { status: 400 }
    );
  }
}

// Proceed with update
await db
  .update(employees)
  .set(validatedData)
  .where(eq(employees.id, params.id));
```

### Business Rule Context

**Crew-Ready Status Significance:**

The Crewing/Done field represents the final checkpoint in employee onboarding. When marked true, it indicates the employee has completed all mandatory requirements and is ready for crew assignment and operational deployment.

The 10 prerequisite fields represent critical onboarding steps:

- **ISP**: International Safety Passport certification
- **Photo**: Employee photo on file
- **Origo**: Origo system registration
- **Mail/lön**: Email and payroll setup complete
- **Bankuppgifter**: Bank account details verified
- **LI**: Life Insurance enrollment
- **Passport**: Passport verification complete
- **Kvitto C17/18, C17**: Mandatory certifications/receipts

Enforcing these prerequisites ensures employees cannot be marked crew-ready until all compliance and operational requirements are met, reducing errors and regulatory risks.

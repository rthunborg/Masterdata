# PWA Icons Required for Story 12.4

## Overview

Story 12.4 (Progressive Web App Installation) requires PWA icons to be created and placed in the `public/icons/` directory.

## Required Icons

The following icons must be created from the Stena Line logo (`public/images/stena-logo.png`):

1. **icon-192x192.png** - 192x192 pixels
   - Used for: Android home screen, iOS home screen (fallback)
   - Format: PNG
   - Requirements: No transparency (iOS requirement), square format

2. **icon-512x512.png** - 512x512 pixels
   - Used for: Android splash screen, high-resolution displays
   - Format: PNG
   - Requirements: No transparency, square format

## Icon Guidelines

### iOS Requirements
- **No transparency** - iOS requires solid backgrounds
- **Square format** - Icons are displayed in square containers
- **Padding** - Leave 10% padding around the logo (safe area)
- **Background color** - Use white (#ffffff) or theme color (#1e40af)

### Android Requirements
- **Adaptive icons supported** - Can use maskable icons
- **Square format** - Icons are displayed in various shapes (circle, square, rounded square)
- **Safe area** - Keep important content within 80% of the icon (center area)

## How to Create Icons

### Option 1: Using Image Editing Software
1. Open `public/images/stena-logo.png` in an image editor (Photoshop, GIMP, Figma, etc.)
2. Create a new canvas at 192x192 pixels
3. Place the logo centered with appropriate padding
4. Export as PNG (no transparency)
5. Repeat for 512x512 pixels

### Option 2: Using Online Tools
- Use tools like [PWA Asset Generator](https://github.com/onderceylan/pwa-asset-generator)
- Or [RealFaviconGenerator](https://realfavicongenerator.net/)

### Option 3: Using Command Line (ImageMagick)
```bash
# Create 192x192 icon
convert public/images/stena-logo.png -resize 172x172 -gravity center -background white -extent 192x192 public/icons/icon-192x192.png

# Create 512x512 icon
convert public/images/stena-logo.png -resize 460x460 -gravity center -background white -extent 512x512 public/icons/icon-512x512.png
```

## Directory Structure

After creating icons, the structure should be:
```
public/
  icons/
    icon-192x192.png
    icon-512x512.png
  images/
    stena-logo.png
    stena-bg.jpg
```

## Testing

After icons are created:
1. Verify icons are accessible at `/icons/icon-192x192.png` and `/icons/icon-512x512.png`
2. Test PWA installation on mobile devices
3. Verify icons appear correctly in the install prompt
4. Verify icons appear on home screen after installation

## User Story

**As a** developer maintaining employee card functionality  
**I want** automated tests for the employee card expansion behavior  
**So that** I can prevent regressions in field visibility and inline editing

---

## Context

The employee card "More" expansion functionality was implemented in Story 9.4 (AC 8) but lacks automated test coverage. Current behavior:

1. **Field Expansion**: "More" button shows all employee fields
2. **Scrolling**: Vertical scroll when content exceeds viewport height
3. **Inline Editing**: All visible fields support editing where permissions allow
4. **Responsive**: Adapts to different mobile screen sizes

Without automated tests, changes to the employee card component could break the expansion functionality.

---

## Acceptance Criteria

### AC1: Employee Card Expansion Behavior Tests
**Given** an employee card in mobile view  
**When** user interacts with the "More" functionality  
**Then** tests verify:

- "More" button is visible when card is collapsed
- Clicking "More" expands card to show all fields
- "Less" button is visible when card is expanded
- Clicking "Less" collapses card back to summary view
- Expansion state persists during re-renders
- All employee fields are visible in expanded view
- No fields are cut off or hidden in expanded state

**Test Count**: 7 expansion behavior tests

**Test Count**: 8 field visibility tests

## Dev Notes

### Employee Card Component Architecture

**Component Structure:**
`	sx
// src/components/dashboard/employee-card.tsx
export function EmployeeCard({ employee, columnConfigs, isHRAdmin }) {
  const [isExpanded, setIsExpanded] = useState(false);
  const [editingField, setEditingField] = useState(null);
  
  const visibleFields = useMemo(() => 
    getVisibleFields(columnConfigs, userRole), 
    [columnConfigs, userRole]
  );
  
  return (
    <Card className="employee-card">
      <CardHeader>
        {/* Summary view fields */}
      </CardHeader>
      
      {isExpanded && (
        <CardContent className="expanded-fields max-h-[70vh] overflow-y-auto">
          {visibleFields.map(field => (
            <EditableField 
              key={field.db_column_name}
              field={field}
              employee={employee}
              canEdit={canEditField(field, userRole)}
              onUpdate={handleFieldUpdate}
            />
          ))}
        </CardContent>
      )}
      
      <CardFooter>
        <Button 
          onClick={() => setIsExpanded(!isExpanded)}
          data-testid={isExpanded ? "collapse-button" : "expand-button"}
        >
          {isExpanded ? "Less" : "More"}
        </Button>
      </CardFooter>
    </Card>
  );
}
`

**Field Visibility Logic:**
`	ypescript
function getVisibleFields(columnConfigs: ColumnConfig[], userRole: UserRole) {
  return columnConfigs
    .filter(config => config.is_visible)
    .filter(config => config.role_permissions[userRole]?.view)
    .sort((a, b) => a.display_order - b.display_order);
}

function canEditField(field: ColumnConfig, userRole: UserRole): boolean {
  return field.role_permissions[userRole]?.edit || false;
}
`

### Testing Patterns

**Expansion Behavior Test:**
`	ypescript
test('clicking More button expands card to show all fields', async () => {
  const mockEmployee = createTestEmployee();
  const mockColumns = createTestColumnConfigs();
  
  const { getByTestId, getByText } = render(
    <EmployeeCard 
      employee={mockEmployee} 
      columnConfigs={mockColumns}
      isHRAdmin={true}
    />
  );
  
  // Initially collapsed
  expect(() => getByTestId('expanded-fields')).toThrow();
  
  // Click More button
  const moreButton = getByTestId('expand-button');
  fireEvent.click(moreButton);
  
  // Should be expanded
  expect(getByTestId('expanded-fields')).toBeInTheDocument();
  expect(getByTestId('collapse-button')).toBeInTheDocument();
  
  // All visible fields should be present
  mockColumns.forEach(column => {
    if (column.is_visible && column.role_permissions.hr_admin.view) {
      expect(getByText(column.column_name)).toBeInTheDocument();
    }
  });
});
`

**Permission-Based Visibility Test:**

**Inline Editing Test:**
`	ypescript
test('clicking editable field enables inline editing', async () => {
  const mockEmployee = createTestEmployee({ first_name: 'John' });
  const mockOnUpdate = jest.fn().mockResolvedValue({});
  
  const { getByTestId, getByDisplayValue } = render(
    <EmployeeCard 
      employee={mockEmployee}
      onUpdate={mockOnUpdate}
      isHRAdmin={true}
    />
  );
  
  // Expand card
  fireEvent.click(getByTestId('expand-button'));
  
  // Click on editable field
  const firstNameField = getByText('John');
  fireEvent.click(firstNameField);
  
  // Should show input field
  const input = getByDisplayValue('John');
  expect(input).toBeInTheDocument();
  expect(input.tagName).toBe('INPUT');
  
  // Edit value and save
  fireEvent.change(input, { target: { value: 'Jonathan' } });
  fireEvent.blur(input);
  
  // Should call update handler
  await waitFor(() => {
    expect(mockOnUpdate).toHaveBeenCalledWith(
      mockEmployee.id,
      'first_name',
      'Jonathan'
    );
  });
});
`

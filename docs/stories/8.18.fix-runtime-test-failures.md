## Dev Notes

### Common Failure Patterns

**1. localStorage Mocking:**
```
Failed to load column widths from localStorage: TypeError: localStorage.getItem is not a function
```
**Solution:** Set up localStorage mock in vitest.setup.ts or test files

**2. Supabase Mocking:**
```
TypeError: supabase.from(...).select is not a function
```
**Solution:** Ensure Supabase client is properly mocked with all methods

**3. URL Parsing:**
```
Error fetching available PE3 dates: TypeError: Failed to parse URL from /api/important-dates/available-pe3
```
**Solution:** Set up base URL in test environment or mock fetch with full URLs

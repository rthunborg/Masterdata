# Story 8.10: PE3 Date Time Selection

## Status

**Done**

---

## Story

**As an** HR Admin,
**I want** to specify time-of-day for PE3 dates (HH:MM format),
**So that** I can schedule specific appointment times for PE3 training.

---

## Acceptance Criteria

1. Database adds `time_value` TIME column to important_dates table (PE3 category only)
2. PE3 date create/edit form displays time picker (HH:MM format, 24-hour) in addition to date picker
3. Time picker supports keyboard input and dropdown selection
4. Important Dates table displays PE3 dates with time (e.g., "March 15, 2025 14:30")
5. Employee assignment dropdown for PE3 shows date with time (e.g., "15/3 14:30")
6. Default time is null/empty (time is optional for PE3 dates)
7. Validation ensures valid time format (00:00 - 23:59)
8. Sorting by PE3 date considers both date and time (chronological order)
9. CSV import supports time parsing (formats: "HH:MM", "HH:MM:SS", ISO datetime)
10. Export includes time in readable format (localized)
11. Filtering by date range includes time consideration
12. Time displays in Swedish locale format (24h format)

## Dev Notes

### Architecture Context

This story adds time-of-day scheduling capability specifically for PE3 training dates. PE3 training sessions require specific appointment times (e.g., 14:30), unlike ÖMC dates (which are two-day spans) or Stena dates (which are date ranges without specific times).

**Design Decision**: Store time as PostgreSQL TIME type in a dedicated `time_value` column on the `important_dates` table. This keeps the `date_value` column focused on date information and allows flexible time handling (nullable for dates that don't need time specificity).

[Source: docs/epic-8-enhanced-employee-management-features.md#story-810]

### Previous Story Context (Story 8.9)

**ÖMC Two-Day Date Format:**
Story 8.9 implemented custom formatting for ÖMC dates (e.g., "8-9 mars 2025"). The same pattern applies here for PE3 dates with time:

- Display format: "15 mars 2025 14:30" (date + time)
- Employee dropdown format: "15/3 14:30" (short date + time)
- EditableCell already supports conditional rendering based on category
- Follow similar pattern: check category, format accordingly

**Formatting Utility Pattern:**
Story 8.9 created `omc-date-formatter.ts` for ÖMC-specific formatting. This story follows the same pattern with `time-formatter.ts` for time-specific operations (validate, parse, format).

[Source: docs/stories/8.9.omc-two-day-date-format.md#dev-notes]

### Data Models

**ImportantDate Interface (Updated):**

Location: `src/lib/types/important-date.ts`

```typescript
export interface ImportantDate {
  id: string;
  week_number: number | null;
  year: number;
  category: string;
  date_description: string;
  /**
   * Date value in flexible format.
   * - For ÖMC category: Stores start date as ISO string (YYYY-MM-DD), end date is implicit +1 day
   * - For other categories: Standard single-date value (YYYY-MM-DD)
   */
  date_value: string;
  /**
   * Time value for PE3 appointments (HH:MM format, 24-hour).
   * - Only used for PE3 category dates
   * - Optional, null if no specific time required
   */
  time_value: string | null; // NEW FIELD
  notes: string | null;
  is_active: boolean;
  max_spots: number;
  remaining_spots: number;
  assigned_employees: AssignedEmployee[];
  created_at: string;
  updated_at: string;
}
```

**Business Rule:**

- time_value is ONLY meaningful for PE3 category dates
- Other categories (ÖMC, Stena, Other) should have time_value = null
- Time format: HH:MM (24-hour), e.g., "14:30", "09:00"
- Display combines date + time: "15 mars 2025 14:30"

### Validation Schema Updates

**File:** `src/lib/validation/important-date-schema.ts`

Add time_value field with custom validation:

```typescript
export const importantDateSchema = z
  .object({
    // ... existing fields
    time_value: z.string().nullable().optional(),
  })
  .refine(
    (data) => {
      // Validate time format if provided
      if (data.time_value && data.time_value.trim() !== '') {
        const result = validateTimeFormat(data.time_value);
        return result.valid;
      }
      return true;
    },
    {
      message: 'Tid måste vara i format HH:MM (00:00 - 23:59)',
      path: ['time_value'],
    }
  );
```

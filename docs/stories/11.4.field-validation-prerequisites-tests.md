### Talmundo Editability Logic (Story 8.4)

**Rules:**
1. `one` field must be `true`
2. At least 24 hours must have passed since `one_timestamp`

**Logic:**
```typescript
function canEditTalmundo(employee: Employee): boolean {
  if (!employee.one) return false;
  if (!employee.one_timestamp) return false;
  
  const hoursSinceOne = (Date.now() - new Date(employee.one_timestamp).getTime()) / (1000 * 60 * 60);
  return hoursSinceOne >= 24;
}
```

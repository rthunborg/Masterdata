# Story 8.12: PE3 Import with Automatic Deadline Calculation

## Status

**Done**

---

## Story

**As an** HR Admin,
**I want** PE3 import to automatically calculate deadline dates,
**So that** I don't have to manually set deadlines for each imported PE3 date.

---

## Acceptance Criteria

1. Rename "Import Dates" feature to "Import PE3 Dates" (button text, modal title)
2. Import functionality automatically sets category to "PE3 Dates" (no user selection, hardcoded)
3. For each imported PE3 date batch, identify the FIRST (earliest) date in the batch
4. Calculate `deadline_cancel` as Monday of the week before the FIRST date
5. Calculate `deadline_submit` as Wednesday of the week before the FIRST date
6. Import preview displays calculated deadlines for user review before saving
7. User can override calculated deadlines during import if needed (editable fields in preview)
8. CSV format documentation updated to explain PE3-specific import and deadline calculation
9. Validation ensures all imported dates are valid PE3 dates (category enforcement)
10. Bulk deadline updates apply consistently across all dates in import batch
11. Import logs show deadline calculation logic for auditing purposes
12. Edge case: Handle dates in first week of year correctly (previous year calculation)

## Dev Notes

### Architecture Context

This story enhances the existing Important Dates CSV import feature (Story 6.4) by specializing it for PE3 dates with automatic deadline calculation. The import functionality is renamed from generic "Import Dates" to "Import PE3 Dates" and hardcoded to work exclusively with the PE3 Dates category.

**Design Decision:** Reuse existing import infrastructure from Story 6.4 but add PE3-specific logic for deadline calculation and category enforcement. The modal component (`import-important-dates-modal.tsx`) is modified rather than creating a separate PE3-specific modal.

**Business Rules:**

- PE3 import ONLY accepts "PE3 Dates" category (hardcoded, no user selection)
- Deadlines are calculated based on the FIRST (earliest) date in the import batch
- `deadline_cancel` = Monday of the week BEFORE the first date
- `deadline_submit` = Wednesday of the week BEFORE the first date
- User can override calculated deadlines if needed (editable in preview)
- All dates in the same import batch share the same deadline values

### PE3 Deadline Calculator Design

**File:** `src/lib/services/pe3-deadline-calculator.ts`

**Key Function:**

```typescript
/**
 * Calculate deadline dates for PE3 import batch
 * Business rule: deadlines are based on the FIRST (earliest) date in the batch
 *
 * @param dates - Array of ISO date strings (YYYY-MM-DD) from CSV import
 * @returns Object with deadline_cancel (Monday) and deadline_submit (Wednesday) of previous week
 */
export function calculatePE3Deadlines(dates: string[]): {
  deadlineCancel: string;
  deadlineSubmit: string;
  firstDate: string;
} {
  if (dates.length === 0) {
    throw new Error('Cannot calculate deadlines: no dates provided');
  }

  // Parse dates and find earliest
  const parsedDates = dates
    .map((d) => new Date(d))
    .sort((a, b) => a.getTime() - b.getTime());
  const firstDate = parsedDates[0];

  // Get week before first date
  const weekBefore = new Date(firstDate);
  weekBefore.setDate(weekBefore.getDate() - 7);

  // Calculate Monday of that week
  const dayOfWeek = weekBefore.getDay(); // 0 (Sunday) to 6 (Saturday)
  const daysToMonday = dayOfWeek === 0 ? 6 : dayOfWeek - 1; // Monday = 1
  const monday = new Date(weekBefore);
  monday.setDate(monday.getDate() - daysToMonday);

  // Wednesday is Monday + 2 days
  const wednesday = new Date(monday);
  wednesday.setDate(wednesday.getDate() + 2);

  // Format as ISO date strings
  return {
    deadlineCancel: monday.toISOString().split('T')[0], // YYYY-MM-DD
    deadlineSubmit: wednesday.toISOString().split('T')[0], // YYYY-MM-DD
    firstDate: firstDate.toISOString().split('T')[0],
  };
}

/**
 * Validate calculated deadlines against business rules
 */
export function validatePE3Deadlines(
  deadlineSubmit: string,
  deadlineCancel: string,
  firstDate: string
): { valid: boolean; error?: string } {
  // Use existing deadline validator from Story 8.11
  return validateDeadlines(deadlineSubmit, deadlineCancel, firstDate);
}
```

**Edge Case Handling:**

```typescript
// Example: First date is January 3, 2025 (Friday of week 1)
// Week before: December 27-31, 2024 (week 52 of 2024)
// Monday = December 30, 2024
// Wednesday = January 1, 2025
//
// This correctly calculates deadlines in previous year when needed
```

### Validation Schema Updates

**File:** `src/lib/utils/important-dates-csv-validator.ts`

Add PE3 category enforcement:

```typescript
export function validatePE3ImportRow(
  row: Record<string, any>,
  rowNumber: number
): { valid: boolean; errors: ValidationError[] } {
  const errors: ValidationError[] = [];

  // Validate category if present
  if (row.category && row.category !== 'PE3 Dates') {
    errors.push({
      row: rowNumber,
      field: 'category',
      message: `Only PE3 dates can be imported. Found: ${row.category}`,
    });
  }

  // Standard validation for other fields
  const baseValidation = validateImportantDateRow(row, rowNumber);

  return {
    valid: errors.length === 0 && baseValidation.valid,
    errors: [...errors, ...baseValidation.errors],
  };
}
```

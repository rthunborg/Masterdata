## Context

Boolean fields on the dashboard are currently edited via a checkbox. This is less clear than desired and does not match the preferred UX. We want a dropdown with explicit Swedish options: “Klart” (true) and “Nej” (false).

This story introduces the dropdown UX for boolean inline edits and ensures correct value mapping and non-redundant rerenders.

## User Story

As an HR user,  
I want boolean fields to be edited via a dropdown with “Klart” or “Nej”  
so that the meaning of the current and selected value is always clear.

## Scope / Notes

- Identify inline-editable boolean fields on the dashboard.  
- Replace checkbox controls in edit mode with a dropdown.  
- Map: **“Klart” → true**, **“Nej” → false**.  
- Ensure no-op edits (entering edit mode and leaving the same option selected) do not send updates or trigger redundant rerenders.

## Acceptance Criteria

- **AC1 – Dropdown instead of checkbox in edit mode**  
  - Given a boolean field currently editable as a checkbox  
  - When I enter inline-edit mode  
  - Then I see a dropdown instead of a checkbox  
  - And the dropdown options are “Klart” and “Nej”.

- **AC2 – Correct preselection**  
  - Given the backend value is true  
  - When I enter edit mode  
  - Then “Klart” is preselected.  
  - Given the value is false  
  - Then “Nej” is preselected.

- **AC3 – Correct persistence**  
  - When I select “Klart” and save  
  - Then the stored value is true.  
  - When I select “Nej” and save  
  - Then the stored value is false.

- **AC4 – Keyboard and accessibility**  
  - When navigating via keyboard  
  - Then I can focus and change the dropdown using standard keyboard interactions  
  - And labels/ARIA (or equivalent) remain correct.

- **AC5 – No-op edit does not cause updates or extra renders**  
  - Given a boolean field with value true or false  
  - And I enter edit mode and leave the selection unchanged  
  - When I exit edit mode  
  - Then no update is sent and there is no redundant rerender for that row/card.

- **AC6 – Dashboard tests updated and passing**  
  - When this story is completed  
  - Then tests are updated/added for boolean dropdown behavior, mapping “Klart/Nej” ↔ true/false, and no-op editing  
  - And the dashboard test suite passes.

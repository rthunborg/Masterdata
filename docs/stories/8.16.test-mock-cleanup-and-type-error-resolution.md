### Testing Standards

**Mock Object Best Practices:**

1. **Type-Specific Patterns:**
   - Employee: Check for `first_name` + `email` + `employee_number`
   - User: Check for `role` + `email`
   - ColumnConfig: Check for `column_name` + `db_column_name`
   - ImportantDate: Check for `event_name` + `event_type`

2. **Required Properties:**
   - Always include `id`, `created_at`, `updated_at`
   - Include all non-optional properties for the type
   - Use appropriate default values for optional properties

3. **Property Values:**
   - Use valid enum values only
   - Use correct types (number vs boolean for loneiva)
   - Use ISO date strings for date fields
   - Use null (not undefined) for nullable fields

### Systematic Cleanup Approach

**Step-by-Step Process:**

1. **Run Type Check First:**

   ```bash
   pnpm tsc --noEmit > type-errors-before.txt
   ```

   - Establish baseline count (should be 209)

2. **Clean Cross-Type Contamination:**
   - Focus on high-impact issues first (User/SessionUser contamination)
   - Verify each file individually after cleanup
   - Run type check after each category: `pnpm tsc --noEmit`

3. **Add Missing Properties:**
   - Use TEST_CLEANUP_ANALYSIS.md as reference
   - Add properties systematically by type
   - Verify type errors reduce with each commit

4. **Fix Enum and Specific Issues:**
   - Search and replace invalid enum values
   - Update specific test type expectations
   - Run type check after each fix

5. **Final Verification:**
   ```bash
   pnpm tsc --noEmit > type-errors-after.txt
   # Should show 0 errors
   pnpm build
   pnpm lint
   ```

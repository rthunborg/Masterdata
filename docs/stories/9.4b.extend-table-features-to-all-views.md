### Task 6: Extend Column Resizing to Column Settings Table

**Status:** **BLOCKED - Technical Limitation**

**Subtasks:**

- [ ] Import localStorage utilities: `saveColumnWidths`, `loadColumnWidths`, `clearColumnWidths`
- [ ] Initialize `columnSizing` state with loaded widths from localStorage (`columnWidths-columnSettings-{userId}`)
- [ ] Configure TanStack Table with `columnResizeMode: 'onChange'`, `minSize: 80`, `maxSize: 500`
- [ ] Add resize handle to column headers
- [ ] Implement debounced save (300ms) on column resize event
- [ ] Add "Reset Column Widths" button to table toolbar
- [ ] Test resizing and persistence across browser sessions

**Technical Blocker:**

The Column Settings table uses a custom implementation with `@dnd-kit` for drag-and-drop row reordering. It does NOT use TanStack Table for rendering, which makes it incompatible with TanStack Table's column resizing feature without a full architectural refactor.

**Current Implementation:**

- Manual table rendering with `<Table>`, `<TableHeader>`, `<TableBody>` components
- Row-level drag-and-drop using `@dnd-kit/core` and `@dnd-kit/sortable`
- Fixed column widths defined in `<colgroup>` with percentage-based widths
- Sortable context wraps individual rows, not the table structure

**Why Column Resizing Can't Be Added:**

1. TanStack Table's `useReactTable` hook manages column state, but this table doesn't use it
2. Column resizing requires `flexRender()` for headers, but this table uses manual JSX rendering
3. `getResizeHandler()` is a TanStack Table column method unavailable in current structure
4. Integrating TanStack Table while maintaining `@dnd-kit` row reordering requires careful coordination

**Recommendation:**
Create a follow-up story to refactor Column Settings table to use TanStack Table v8 with both:

- Column resizing (horizontal drag)
- Row reordering (vertical drag via @dnd-kit integration)

**Estimated Refactor Effort:** 4-6 hours (separate story)

**Files to Modify:**

- `src/components/admin/column-settings-table.tsx` (or equivalent)

**useMediaQuery Hook Example:**

```typescript
import { useState, useEffect } from 'react';

export function useMediaQuery(query: string): boolean {
  const [matches, setMatches] = useState(false);

  useEffect(() => {
    const media = window.matchMedia(query);
    if (media.matches !== matches) {
      setMatches(media.matches);
    }
    const listener = () => setMatches(media.matches);
    media.addEventListener('change', listener);
    return () => media.removeEventListener('change', listener);
  }, [matches, query]);

  return matches;
}
```

### Debug Log

**Technical Discovery: Column Settings Table Architecture**

The Column Settings table presents a unique challenge:

- Uses `@dnd-kit/core` and `@dnd-kit/sortable` for vertical row reordering
- Manual table rendering (not using TanStack Table's `useReactTable` hook)
- Fixed column widths defined via `<colgroup>` with percentage-based widths

**Attempted Approach:**
Initially attempted to add TanStack Table's column resizing alongside existing drag-and-drop:

1. Added imports for `useReactTable`, `ColumnDef`, `ColumnSizingState`
2. Discovered that TanStack Table's `flexRender()` is incompatible with `@dnd-kit`'s `SortableContext`
3. TanStack Table expects full control over rendering, while `@dnd-kit` needs manual row rendering

**Conflict Analysis:**

- TanStack Table uses `table.getHeaderGroups()` and `flexRender()` for headers
- `@dnd-kit` uses `<SortableContext>` wrapping `<TableBody>` with manual `<TableRow>` components
- Column resizing requires `header.getResizeHandler()` which isn't available in manual rendering

**Resolution:**
Documented technical blocker and recommended separate refactor story. This table requires:

1. Convert to TanStack Table `useReactTable` hook
2. Integrate `@dnd-kit` row reordering WITH TanStack Table (example: https://tanstack.com/table/latest/docs/framework/react/examples/row-dnd)
3. Add column resizing after integration complete

**Estimated Refactor:** 4-6 hours (separate story recommended)

# Story 7.5: Dashboard Filter & UX Improvements

## Status

**Approved**

---

## Story

**As a** user,  
**I want** functional filters for archived/terminated employees and improved locale selector,  
**so that** I can navigate employee data efficiently and switch languages comfortably.

---

## Acceptance Criteria

1. "Show Archived" filter checkbox/toggle implemented and functional
2. When "Show Archived" enabled, archived employees appear in table with visual distinction (grayed out, badge, or separate section)
3. "Show Terminated" filter checkbox/toggle implemented and functional
4. When "Show Terminated" enabled, terminated employees appear with visual distinction
5. Filters can be combined (show both archived and terminated simultaneously)
6. Filter state persists during session (not across page refreshes)
7. "Live" button removed from dashboard (purpose unclear, not in requirements)
8. Locale selector gap between flag and language code reduced (SE SV minimal spacing, same for GB EN)
9. Terminate Employee and Archive Employee buttons switched in action menu (Terminate first, Archive second)
10. All filter interactions work smoothly with search and sort functionality

## Dev Notes

### Filter State Management

Use React state for filters:
` ypescript
const [showArchived, setShowArchived] = useState(false);
const [showTerminated, setShowTerminated] = useState(false);

// Build query filters
const queryFilters = useMemo(() => {
const filters = [];
if (!showArchived) filters.push(eq(employees.is_archived, false));
if (!showTerminated) filters.push(eq(employees.is_terminated, false));
return filters;
}, [showArchived, showTerminated]);
`

### Visual Distinction Styles

**Archived Employees:**

- Background: g-gray-100 dark:bg-gray-800 (lighter than normal rows)
- Badge: <Badge variant="secondary">Archived</Badge>

**Terminated Employees:**

- Text color: ext-red-600 dark:text-red-400
- Badge: <Badge variant="destructive">Terminated</Badge>
- Optional: Strikethrough on name

**Combined (Archived + Terminated):**

- Both styles applied, badge shows both states

### Session Storage

` ypescript
// Save filter state
useEffect(() => {
sessionStorage.setItem('employeeFilters', JSON.stringify({
showArchived,
showTerminated
}));
}, [showArchived, showTerminated]);

// Load filter state on mount
useEffect(() => {
const saved = sessionStorage.getItem('employeeFilters');
if (saved) {
const { showArchived, showTerminated } = JSON.parse(saved);
setShowArchived(showArchived);
setShowTerminated(showTerminated);
}
}, []);
`

### Key Test Patterns

**Pattern 1: Spot Decrement Test**
```typescript
test('should decrement remaining_spots when assigning employee', async () => {
  const date = await createTestDate({ remaining_spots: 10 });
  const employee = await createTestEmployee({ omc_date: date.date_value });
  
  const updatedDate = await getDateById(date.id);
  expect(updatedDate.remaining_spots).toBe(9);
});
```

**Pattern 2: Capacity Limit Test**
```typescript
test('should throw 409 error when assigning to full date', async () => {
  const date = await createTestDate({ remaining_spots: 0 });
  const employee = createTestEmployee({ omc_date: date.date_value });
  
  await expect(createEmployee(employee)).rejects.toThrow(/kapacitet/);
});
```

**Pattern 3: Transaction Rollback Test**
```typescript
test('should rollback spot decrement if assignment fails', async () => {
```

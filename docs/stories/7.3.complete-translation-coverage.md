# Story 7.3: Complete Translation Coverage for All Pages

## Status

**Approved**

---

## Story

**As a** user,  
**I want** complete Swedish and English translations for all UI text,  
**so that** I can use the system in my preferred language without confusion.

---

## Acceptance Criteria

1. **User Settings page translations (HR Admin only):** "Användarhantering" "User Management", "Skapa och hantera användarkonton med rolltilldelningar" "Create and manage user accounts with role assignments"
2. **Column Settings page translations (HR Admin only):** "Show" "Visa", "Type" "Typ", "Category" "Kategori", "Visibility" "Synlighet", "Actions" "Åtgärder", "Hidden" "Dold", "Endast stamdata" "Endast masterdata", "Kolumninställningar" "Column Settings", "Konfigurera vilka roller kan visa och redigera specifika kolumner" "Configure which roles can view and edit specific columns"
3. **Important Dates page translations (HR Admin only):** All text including "Viktiga datum", "Import Dates" "Importera datum", table headers, empty states
4. **Dashboard page translations:** "Personalhantering", "Visa detaljer", "Lägg till anställd", "Importera anställda", "Alla", "Inga anställda hittades" and reverse translations for "Show Archived", "Show Terminated", "View As", "Search employees..."
5. **Archive/Terminate dialog translations:** Complete Swedish translations for dialog title, message, and buttons
6. All translations added to `messages/en.json` and `messages/sv.json`
7. Translation keys follow consistent naming convention
8. No hardcoded strings remain in any component
9. Language toggle updates all text immediately without page refresh
10. Manual testing confirms all pages display correctly in both languages (note: User Settings, Column Settings, and Important Dates are HR Admin only)

## Dev Notes

### Translation Infrastructure

The project uses **next-intl** for internationalization:

- Translation files: `messages/en.json`, `messages/sv.json`
- Hook usage: `const t = useTranslations('namespace')`
- Interpolation: `{t('key', {name: employeeName})}`
- Current locale access: `const locale = useLocale()`

### Naming Convention

Follow this pattern for translation keys:
`pageName.section.element`

Examples:

- `admin.users.pageTitle`
- `dashboard.toolbar.addEmployee`
- `dialogs.archive.message`
- `importantDates.table.weekNumber`

### Source Tree References

- Translation files: `messages/en.json`, `messages/sv.json`
- User Settings page: `src/app/[locale]/admin/users/page.tsx`

## Context

Editing the `loneniva` field currently crashes the app instead of opening a dropdown with options 0–7. This blocks users from editing salary level and disrupts dashboard usage.

This story focuses on preventing the crash, implementing the correct dropdown behavior, and avoiding redundant rerenders for no-op edits.

## User Story

As an HR user,  
I want to edit `loneniva` via a safe 0–7 dropdown  
so that I can adjust salary level without the application crashing.

## Scope / Notes

- Treat `loneniva` as an enumerated field with allowed values `0–7`.  
- Fix the crash and wire up the correct dropdown behavior and persistence.
- Capture/log the error cause where possible.
- Ensure no-op edits (entering edit mode and leaving the same value selected) do not send updates or trigger redundant rerenders.

## Acceptance Criteria

- **AC1 – No crash on edit**  
  - Given I am on a page where `loneniva` is shown as inline-editable  
  - When I click to edit `loneniva`  
  - Then the app does not crash and remains responsive.

- **AC2 – Dropdown with 0–7**  
  - When `loneniva` enters edit mode  
  - Then I see a dropdown with selectable values `0, 1, 2, 3, 4, 5, 6, 7`  
  - And only these values are allowed.

- **AC3 – Persisting selected value**  
  - When I select one of the allowed values and save  
  - Then the selected value is persisted  
  - And is shown correctly after save and page reload.

- **AC4 – Error handling without crash**  
  - If the API rejects the update  
  - Then the UI shows a user-friendly Swedish error message, consistent with the app’s patterns  
  - And the app does not crash.

- **AC5 – No-op edit does not cause updates or extra renders**  
  - Given `loneniva` already has a value N (0–7)  
  - And I enter edit mode and leave N selected  
  - When I exit edit mode  
  - Then no update is sent and there is no redundant rerender for that row/card.

- **AC6 – Dashboard tests updated and passing**  
  - When this story is completed  
  - Then tests are updated/added for the `loneniva` dropdown, crash-free behavior, and no-op editing  
  - And the full dashboard test suite is green.

# Story 14.2: PE3 Deadline Notifications (Submit / Cancel)

## Status

**Ready for Development**

---

## Story

**As an** HR admin,  
**I want** to receive a consolidated email on each PE3 submission/cancellation deadline date listing all affected PE3 dates and assigned employees,  
**so that** I don't miss critical administrative deadlines.

---

## Acceptance Criteria

**AC1:** Given PE3 rows where `deadline_submit = today`, when job runs, one "submit" email is sent to all hr_admin emails.

**AC2:** The submit email body includes a list of all PE3 entries with `deadline_submit = today`, each showing:
- PE3 date identifier(s) (e.g., start/end, title, location)
- Assigned employee name if present, otherwise explicitly "Unassigned".

**AC3:** Given PE3 rows where `deadline_cancel = today`, when job runs, one "cancel" email is sent to all hr_admin emails with equivalent listing.

**AC4:** If no PE3 entries match today's deadline(s), no PE3 deadline emails are sent.

**AC5:** Idempotency: each deadline email is sent at most once per day.
- Store marker per deadline type/date, e.g. `pe3_submit_notice_sent_for_date`, `pe3_cancel_notice_sent_for_date`.

**AC6:** Emails clearly label whether the deadline is for submit or cancel.

---

## Business Rules

1. `important_dates` table contains PE3 entries.
2. Only PE3 entries have:
   - `deadline_submit` (date)
   - `deadline_cancel` (date)
3. Many PE3 entries can share the same deadlines.
4. On a day when the job runs and today matches a deadline:
   - If `today == deadline_submit` for any PE3 entries: Send a "Last date to submit PE3 spots" email.
   - If `today == deadline_cancel` for any PE3 entries: Send a "Last date to cancel PE3 spots" email.
5. Each email groups all PE3 dates matching the triggered deadline:
   - Include date info (whatever identifies the PE3 date: e.g., start/end, title, location)
   - If an employee is assigned, include their name.
6. If both deadlines occur the same day, send two separate emails (one submit, one cancel), unless you later want a combined email.
7. **Idempotency:** Each deadline email is sent at most once per day per deadline type.

## Dev Notes

### Query Approach

**Submit Deadline:**
```sql
SELECT id.*, e.name as employee_name
FROM important_dates id
LEFT JOIN employees e ON id.employee_id = e.id
WHERE id.type = 'PE3'
  AND id.deadline_submit = CURRENT_DATE
```

**Cancel Deadline:**
```sql
SELECT id.*, e.name as employee_name
FROM important_dates id
LEFT JOIN employees e ON id.employee_id = e.id
WHERE id.type = 'PE3'
  AND id.deadline_cancel = CURRENT_DATE
```

**Check Notification Sent:**
```sql
SELECT COUNT(*) > 0 as already_sent
FROM pe3_notifications_log
WHERE deadline_type = 'submit' -- or 'cancel'
  AND deadline_date = CURRENT_DATE
```

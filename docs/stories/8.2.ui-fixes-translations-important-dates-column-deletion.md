   - "Activate" button → Uses existing `admin.activateButton` translation (add if missing)

### Important Dates Enhancements (AC 2-6)

2. **PE3 Dates Category**: Add "PE3 Dates" as a new category option in Important Dates form:
   - Add to category dropdown alongside "Stena Dates", "ÖMC Dates", and "Other"
   - Translations: English: "PE3 Dates", Swedish: "PE3-datum"
   - Category value stored in database as "PE3 Dates"

3. **Date Picker for Date Value**: Replace text input with HTML5 date picker for date value field:
   - Use `<input type="date">` for the date_value field
   - Provides native date picker interface across browsers
   - Stores selected date in ISO format (YYYY-MM-DD) or keeps text format if free-form dates needed
   - Maintains backward compatibility with existing date_value formats like "15-16/2" or "10/4"

4. **Optional Date Description**: Make date description field optional instead of required:
   - Remove required validation from `date_description` field in schema
   - Remove red asterisk (\*) from field label in form
   - Allow creation of important dates without description

5. **Auto-Populate Week Number from Date**: When user selects a date value, automatically calculate and populate week number:
   - Trigger calculation when date picker value changes
   - Calculate ISO week number from selected date
   - Auto-fill week_number field if empty
   - User can still manually override the calculated week number
   - Only applies when date_value is in valid ISO date format (YYYY-MM-DD)

6. **Reorder Form Fields**: Adjust field order in Important Dates form for better UX:
   - **New order**: Category → Year → Date Value → Week Number → Date Description → Notes
   - **Rationale**: Primary fields (category, year, date) first, then auto-calculated field (week), then optional descriptive fields last
   - Maintain 2-column grid layout where appropriate

### Column Management Enhancement (AC 7)

7. **Allow Deletion of Masterdata Columns**: HR Admin must be able to delete columns marked as masterdata (stamdata):
   - Remove `is_masterdata` check that currently disables delete button
   - Allow HR Admin to delete ANY column including those with `is_masterdata: true`
   - Show confirmation dialog before deletion (existing behavior)
   - Warning in dialog: "Deleting this masterdata column will remove it from all employee records. This cannot be undone."
   - Only HR Admin role can delete columns (existing role-based access control maintained)

### Week Number Calculation

ISO 8601 week date system:

- Week 1 is the first week with a Thursday in the new year
- Weeks start on Monday
- Can be calculated using JavaScript Date methods

Example implementation approach:

```typescript
function getISOWeek(date: Date): number {
  const target = new Date(date.valueOf());
  const dayNr = (date.getDay() + 6) % 7;
  target.setDate(target.getDate() - dayNr + 3);
  const firstThursday = target.valueOf();
  target.setMonth(0, 1);
  if (target.getDay() !== 4) {
    target.setMonth(0, 1 + ((4 - target.getDay() + 7) % 7));
  }
  return 1 + Math.ceil((firstThursday - target.valueOf()) / 604800000);
}
```

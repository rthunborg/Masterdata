# Story 7.2: External Party Custom Column Seeding & Defaults

## Status

**Approved**

---

## Story

**As an** External Party user,  
**I want** my custom columns pre-configured at initial setup,  
**so that** I can start using the system immediately without manual column creation.

---

## Acceptance Criteria

1. **ÖMC Custom columns** seeded in column_config with edit permissions for ÖMC role: Hotel Required?, Room Number (Shared), Dietary Requirement?, Joining Instructions sent, Candidate Confirmed, Seably, Receipt C-17, C-17 Certificate, Receipt C-18, C-18 Certificate, ÖMC Certificate, Uploaded in CrewSF, Completed
2. **Payroll Custom columns** seeded: Ersatt, Fartyg, Klart/sign, Notering
3. **Sodexo Custom columns:** None (as specified in feedback)
4. **Toplux Custom columns** seeded: Stena ID- Origo nummer, Beställning gjord, Fartyg, Skickat beställning till Fartyg/Warehouse, Mottaget, Kontaktat medarbetare, Uthämtat, Mottagit kort, Skickat kort till fartyg
5. Column types correctly defined: ÖMC (11 boolean, 2 text), Payroll (4 text), Toplux (3 text, 6 date)
6. Custom columns appear in correct order as specified in feedback
7. Custom columns isolated per role (ÖMC cannot see Payroll columns, etc.)
8. Empty values (null) for all employees initially in custom column data tables
9. External parties can edit their custom column values immediately after login
10. HR Admin can view all custom columns in "View As" preview mode

## Dev Notes

### Custom Column Configuration Pattern

Each custom column follows this structure:
`sql
INSERT INTO column_config (column_name, column_type, is_masterdata, display_order, role_permissions)
VALUES (
  'Column Name',
  'text|boolean|date',
  false,
  sequence_number,
  '{"role_name": {"view": true, "edit": true}, "hr_admin": {"view": true, "edit": false}}'::jsonb
);
`

### Column Type Definitions

**ÖMC Columns:**

- **Boolean**: Hotel Required?, Dietary Requirement?, Joining Instructions sent, Candidate Confirmed, Receipt C-17, C-17 Certificate, Receipt C-18, C-18 Certificate, ÖMC Certificate, Uploaded in CrewSF, Completed
- **Text**: Room Number (Shared), Seably

**Payroll Columns:**

- **Text**: All columns (Ersatt, Fartyg, Klart/sign, Notering)

**Toplux Columns:**

- **Text**: Stena ID- Origo nummer, Fartyg, Kontaktat medarbetare
- **Date**: Beställning gjord, Skickat beställning till Fartyg/Warehouse, Mottaget, Uthämtat, Mottagit kort, Skickat kort till fartyg

### Display Order Strategy

Custom columns should be ordered sequentially within each role group:

- ÖMC: display_order starting at 100
- Payroll: display_order starting at 200
- Toplux: display_order starting at 300

This prevents conflicts with masterdata columns (1-24).

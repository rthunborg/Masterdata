## Dev Notes

### Debugging Strategy

**For Auth Issues:**
1. Check test file for auth mock setup
2. Verify `requireAuthAPI`/`requireHRAdminAPI` is mocked
3. Ensure mock returns proper user object
4. Check headers if using NextRequest

**For Business Logic:**
1. Read implementation code first
2. Understand the business rule being tested
3. Verify test expectation aligns with requirements
4. Check if implementation has bug or test is wrong

**For Component Issues:**
1. Run test in isolation to see detailed error
2. Check component implementation for structural changes
3. Look for i18n issues missed in Story 8.18
4. Verify component is rendering expected elements

### Investigation Commands

```bash
# Run specific test with verbose output
pnpm test <test-file> --reporter=verbose

# Run test and capture detailed output
pnpm test <test-file> > output.txt 2>&1

# Check specific pattern in test output
pnpm test <test-file> 2>&1 | findstr "FAIL"
pnpm test <test-file> 2>&1 | findstr "401"
```

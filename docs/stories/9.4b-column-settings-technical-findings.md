**Story:** 9.4b - Extend Table Features to All Views

## Executive Summary

During implementation of Story 9.4b, column resizing was successfully added to the **Important Dates** and **User Management** tables. However, the **Column Settings** table presents a **technical blocker** that prevents column resizing from being implemented without a significant architectural refactor.

**Status:**

- ✅ Important Dates Table: Column resizing implemented
- ✅ User Management Table: Column resizing implemented (includes full TanStack Table refactor)
- ⚠️ Column Settings Table: **BLOCKED** - Requires separate story for refactor

**Recommendation:** Create follow-up story for Column Settings table refactor (estimated 4-6 hours).

---

## Technical Blocker Details

### Current Architecture

The Column Settings table (`src/components/admin/column-settings-table.tsx`) uses a **custom implementation** that is fundamentally incompatible with TanStack Table's column resizing feature:

**Technology Stack:**

- `@dnd-kit/core` and `@dnd-kit/sortable` for drag-and-drop row reordering (vertical)
- Manual table rendering using UI components directly
- Fixed column widths defined via `<colgroup>` with percentage-based widths
- No TanStack Table `useReactTable` hook

**Code Structure:**

```tsx
// Current implementation
<Table>
  <colgroup>
    <col style={{ width: '3%' }} />  // Fixed percentages
    <col style={{ width: '14%' }} />
    // ... more fixed columns
  </colgroup>
  <TableHeader>
    <TableRow>
      <TableHead>Manual JSX</TableHead>  // No flexRender
    </TableRow>
  </TableHeader>
  <TableBody>
    <SortableContext items={items}>  // @dnd-kit wrapping
      {items.map(column => (
        <DraggableRow ... />  // Custom sortable component
      ))}
    </SortableContext>
  </TableBody>
</Table>
```

### Why Column Resizing Can't Be Added

TanStack Table's column resizing requires:

1. **`useReactTable` Hook**: Manages column state including sizing
   - ❌ Not present in current implementation

2. **`flexRender()` for Headers**: Renders headers with resize handlers
   - ❌ Table uses manual JSX rendering

3. **Column Instance Methods**: `getResizeHandler()`, `getIsResizing()`, `getSize()`
   - ❌ Not available without TanStack Table

4. **State Management**: `columnSizing` state tracked by TanStack Table
   - ❌ Would conflict with existing @dnd-kit state

**Attempted Integration:** Initial attempt showed that wrapping headers with TanStack Table while maintaining @dnd-kit for rows creates state management conflicts and breaks the drag-and-drop functionality.

## Recommended Solution

### Option 1: Create Follow-Up Story (Recommended)

**Story Title:** "Refactor Column Settings Table to TanStack Table with Row DnD + Column Resizing"

**Scope:**

1. Convert table to use TanStack Table `useReactTable` hook
2. Integrate @dnd-kit row reordering with TanStack Table
   - Reference: [TanStack Table Row DnD Example](https://tanstack.com/table/latest/docs/framework/react/examples/row-dnd)
3. Add column resizing functionality
4. Add localStorage persistence for column widths
5. Add Reset Column Widths button
6. Test row reordering still works correctly
7. Test column resizing works correctly

**Estimated Effort:** 4-6 hours

**Benefits:**

- Column Settings table gains feature parity with other tables
- Improved code maintainability (standardized on TanStack Table)
- Future features (like column hiding) easier to add

**Risks:**

- Potential regression in existing row reordering functionality
- Requires thorough testing of drag-and-drop

### Option 2: Skip Feature for Column Settings Table

**Rationale:**

- Column Settings is an admin-only configuration table
- Used infrequently compared to Dashboard and Important Dates
- Current fixed column widths are acceptable for this use case

**Impact:**

- Minor UX inconsistency (2 of 3 tables have resizing)
- No functional loss (table is fully usable as-is)

**Benefits:**

- Zero development time
- No risk of regression

---

## Implementation Notes

If proceeding with Option 1 (follow-up story), the implementation should:

1. **Review TanStack Table + @dnd-kit Integration**
   - Study official TanStack Table row DnD example
   - Understand how to coordinate both libraries

2. **Incremental Refactor**
   - Step 1: Convert to TanStack Table (keep fixed widths)
   - Step 2: Verify row drag-and-drop still works
   - Step 3: Add column resizing
   - Step 4: Test both features together

3. **Testing Focus**
   - Row reordering: Ensure column order updates persist
   - Column resizing: Ensure widths persist across sessions
   - Interaction: Verify no conflicts between row drag and column resize

4. **Fallback Plan**
   - If integration proves too complex, consider separate controls:
     - Buttons for moving columns up/down (instead of drag-and-drop)
     - This would simplify TanStack Table integration

## Current Workaround

The Column Settings table currently:

- ✅ Displays all data correctly
- ✅ Supports row drag-and-drop reordering
- ✅ Has editable cells
- ✅ Shows category colors

**User Impact:** Minimal - most users don't adjust column widths in admin configuration tables.

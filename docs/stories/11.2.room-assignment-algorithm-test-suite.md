## Context

Story 8.16 implemented the ÖMC room assignment algorithm (FR40) with complex business rules:

1. First employee for a date gets room 1
2. CHEF rank gets next available private room
3. SEV rank shares room with same gender (max 2 per room)
4. SEV gets new room if no same-gender match or room full
5. Room recalculation when dates/hotels change

**Current State**: ❌ No tests exist for room assignment algorithm

**Business Rules to Test (FR40):**
- First employee → room 1
- CHEF → private room (incremented)
- SEV → shared room (same gender, max 2)
- SEV → new room (no match or room full)
- Recalculation on date change
- Recalculation on hotel_required toggle
- Gender constraint enforcement
- Concurrent room assignment handling

### Room Assignment Algorithm (FR40)

```typescript
/**
 * Room Assignment Algorithm (Story 8.16 / FR40)
 * 
 * Input: ÖMC date, employee list (sorted by rank, then hire_date)
 * Output: Map<employeeId, roomNumber>
 * 
 * Pseudocode:
 * 1. Filter employees by date and hotel_required=true
 * 2. Sort by rank (CHEF first), then hire_date (ascending)
 * 3. Initialize rooms: Map<roomNumber, { occupants: string[], gender: string }>
 * 4. For each employee:
 *    a. If first employee OR rank=CHEF:
 *       - Assign next available room (private)
 *    b. If rank=SEV:
 *       - Find room with 1 occupant matching gender
 *       - If found: assign to that room
 *       - Else: assign next available room
 * 5. Return room assignments
 */
```

```typescript
export async function createEmployeesForDate(
  dateValue: string,
  count: number,
  options: Partial<Employee> = {}
) {
  const employees = [];
  for (let i = 0; i < count; i++) {
    const employee = await createTestEmployee({
      omc_date: dateValue,
      hotel_required: true,
      ...options
    });
    employees.push(employee);
  }
  return employees;
}

export async function verifyRoomAssignments(dateId: string) {
  const employees = await getEmployeesByDate(dateId);
  const rooms = new Map<number, string[]>();
  
  for (const emp of employees) {
    if (!emp.hotel_room_number) continue;
    
    if (!rooms.has(emp.hotel_room_number)) {
      rooms.set(emp.hotel_room_number, []);
    }
    rooms.get(emp.hotel_room_number).push(emp.id);
  }
  
  // Validate constraints
  for (const [roomNum, occupants] of rooms.entries()) {
    const emps = employees.filter(e => occupants.includes(e.id));
    
    // CHEF rooms should have 1 occupant
    if (emps.some(e => e.rank === 'CHEF')) {
      expect(occupants).toHaveLength(1);
    }
    
    // SEV rooms should have max 2 occupants
    if (emps.every(e => e.rank === 'SEV')) {
      expect(occupants.length).toBeLessThanOrEqual(2);
      
      // Same gender
      const genders = [...new Set(emps.map(e => e.gender))];
      expect(genders).toHaveLength(1);
    }
  }
  
  return rooms;
}

export async function getRoomOccupants(dateId: string, roomNumber: number) {
  const employees = await getEmployeesByDate(dateId);
  return employees.filter(e => e.hotel_room_number === roomNumber);
}
```
